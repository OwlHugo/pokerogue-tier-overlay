Is it strong from here?

The Magikarp in front of you is useless. The Gyarados it turns into is not, and the Mega it can reach even less so. The overlay reads the whole line before you decide, while the ball is still in your bag.

  1. What you met Magikarp Still grows
  2. What it becomes Gyarados Good
  3. Its ceiling Gyarados-Mega Very good

Those are the overlay's own words. Over that Magikarp it prints Good → Gyarados: the verdict, and where the verdict comes from. The Mega is not in the sentence — it shows up as a +M mark, and only when it is genuinely better than where the line already ends. Behind the verdict sits Smogon's species ranking, the best public measure of a grown Pokémon. PokéRogue has none of its own, so the overlay borrows it and says the result in plain words.

Where it shows up

Three screens, one question

Every surface answers the same thing: is this worth the ball, and where does it lead?

Battle

A verdict above each enemy — Good → Gyarados — plus +M or +G when a Mega or Gigantamax beats where the line already ends.

Starter select

One letter per icon across the whole grid, following filters and scroll because the game draws it. The focused starter gets the verdict spelled out.

Guide panel

Four tabs — enemy, team, biome, destinations — and a legend for the letters. Open a row for the evolution line graded step by step, the abilities, and how hard the catch is.

Not a Smogon reader

The parts that only make sense here

A competitive ranking answers one question. A roguelite asks others, and these are the ones the overlay went and answered on its own.

Snowball abilities

Some abilities stack a stat on every knockout and keep it between waves. That is a Pokémon which clears waves by itself — a roguelite property Smogon has no reason to score. The panel flags it.

Catch, in words

The game holds a catch rate as a number. The panel says very easy, easy, average, hard, very hard — read straight from the object in memory, so it tracks whatever build you are running.

It repairs the game

PokéRogue can write the literal text undefined into its own starterPrefs_ storage, and the starter screen then refuses to load. The overlay clears those entries before it draws anything.

Install

Two things, once

  1. Install a userscript manager

    Tampermonkey or Violentmonkey. Chrome, Firefox, Edge and Safari on desktop, Firefox on Android.

  2. Add the overlay

    Install the script, then open pokerogue.net. The badge appears on the next encounter.

On Chrome you also have to allow user scripts. Since Chrome 138 that switch lives on the manager's own entry in chrome://extensions, as Allow user scripts — and it starts off for anything installed after that change. Older Chrome builds use the global Developer mode toggle instead. Firefox needs neither.

Honest limits

What it will not do for you

The ranking underneath comes from Smogon's competitive metagame, which is not the same thing as strength in PokéRogue — the game has passives, fusions and items Smogon never modelled. The verdict is about the species, not about your run.

It does not calculate damage, does not compute weaknesses, and does not tell you which Pokémon to release. It says nothing about Terastallization, which PokéRogue does have. It ignores your Pokédex IVs, even though catching more of a species raises the IVs its starter inherits — a long game the badge does not play.

When a species is not in Smogon's catalog it shows ? rather than inventing a tier. When it cannot find the game, it says so in red instead of showing a number it does not have.
