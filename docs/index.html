The ball is the decision.

A Magikarp is LC and looks like trash. It becomes Gyarados, which is RU — and Mega Gyarados is OU. The overlay tells you that while the ball is still in your bag.

Where it shows up

Three screens, one question

Every surface answers the same thing: is this worth the ball, and where does it lead?

Battle

A badge above each enemy, with its current tier and the best tier anything in its line can reach — evolution, Mega and Gigantamax included.

Starter select

The best reachable tier on all 572 icons in the grid, following filters and scroll, because it is drawn by the game itself.

Guide panel

Tabs for the enemy, your team, the current biome and where that biome leads. Closed until you open it.

Editorial line

What it refuses to show

A Smogon set carries data PokéRogue does not have. Showing all of it would look thorough and help nobody.

EVs
PokéRogue has no EVs. Stats rise through vitamins, which are reward modifiers.
IVs
They exist, but are rolled at the encounter. You do not choose them.
Held item
Items come from a pool per modifier tier, not the competitive catalog. There are no Z-crystals.
Z / Dynamax sets
Mechanics the game does not implement.

Nature stays, because it is the only one you can act on — PokéRogue has Mints in the modifier pool.

Install

Two things, once

  1. Install a userscript manager

    Tampermonkey or Violentmonkey. Chrome, Firefox, Edge and Safari on desktop, Firefox on Android.

  2. Add the overlay

    Install the script, then open pokerogue.net. The badge appears on the next encounter.

On Chrome you also have to switch on Developer mode at chrome://extensions — since Manifest V3, userscript managers cannot run without it. Firefox needs nothing extra.

Honest limits

What it will not do for you

Tier measures strength in Smogon's competitive metagame, which is not the same thing as strength in PokéRogue — the game has passives, fusions and items Smogon does not model. It is a signal, not a verdict.

It does not calculate damage, does not compute weaknesses, and does not tell you which Pokémon to release. When a species is not in Smogon's catalog it shows ? rather than inventing a tier. When it cannot find the game, it says so in red instead of showing a number it does not have.
